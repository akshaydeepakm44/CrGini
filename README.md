# CreativeGini — Autonomous AI Growth Engine

This monorepo contains the frontend web application and the backend services for CreativeGini.

## Project Structure

```
creativegini-main/
├── backend/          # Backend API & services
└── frontend/         # React + Vite frontend application
```

## Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
Navigate to the `backend/` directory to run backend services.
